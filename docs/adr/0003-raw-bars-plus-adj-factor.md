# ADR-0003: 原始行情与复权因子原样落库，复权价读取时计算

- 状态：已接受
- 日期：2026-08-03（issue #1 决策，2026-08-04 补录）

## 背景

复权价格（前复权/后复权）是回测等场景的必需品。可选方案：(a) 同步时直接存 Tushare 的复权后行情或预先算好的复权价；(b) 只存未复权行情 + 复权因子两份原料，复权价在读取时计算。

## 决策

采用 (b)：**Raw Daily Bar 与 Adjustment Factor 均从 Tushare 原样落库，不做任何计算或加工**。任何价格基准（不复权 / 前复权 / 后复权）都在读取侧由两份原料计算得出。

已知事实（Tushare 官方说明）：复权因子在停牌交易日也会补齐，因此因子表与行情表的日期**可能不对齐**——读取侧 join 时必须容忍，不得以两表日期一致为前提。

## 后果

- 存储层是可信的单一事实来源：任何计算 bug 都不会污染原料，重算即可恢复。
- 新增复权口径不需要重跑同步。
- 代价：读取侧每次都要 join + 计算（复杂度和计算量上移）；读取接口需明确处理日期不对齐（停牌日有因子无行情）。
