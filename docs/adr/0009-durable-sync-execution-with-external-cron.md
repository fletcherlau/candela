# ADR-0009: 外部 cron 触发与持久同步执行分离

- 状态：已接受
- 日期：2026-09-09
- 部分取代：ADR-0001 关于服务无状态、内部不含任何调度逻辑的约束；保留每日业务触发由系统 cron 负责的决定。

用户要求同步不依赖浏览器连接，支持排队、取消、仅重试失败对象及重启恢复，因此原有随请求执行且没有持久执行状态的方式不足以满足需求。syncer 新增基于 MySQL 的持久执行协调，保存固定对象与日期范围、分段检查点、执行权和取消状态；HTTP、机器人及 one-shot 入口均经过同一协调边界，避免绕过对象互斥。

每日何时发起同步仍由外部系统 cron 决定，按 Asia/Shanghai 的 18:00 触发；服务内只负责已提交工作的执行、排队及恢复，不新增每日业务定时器。该选择复用现有 MySQL，不引入额外消息队列；代价是需维护事务一致的检查点、执行权失效保护及可恢复工作状态，并使用真实数据库测试验证故障行为。此决策已获批准，业务实现尚未完成。
