# ADR-0006: 在统一 Candela 网站中提供市场总览

- 状态：已接受
- 日期：2026-08-31（既有讨论决策，2026-09-09 按后续确认补录）

建设带统一入口与导航的 Candela 网站，市场总览和数据管理使用独立页面，保留已有研究页面，不把本次功能做成小市值轮动专属的孤立页面。市场总览同时展示正式及暂算的月度市场状态和策略类型提示；数据维护操作归数据管理。

网站用于个人访问，沿用用户已经搭建的 Cloudflare Tunnel 与 Zero Trust 登录。首版不引入 Authing 或多用户权限系统；既有研究页不要求全部迁移到新前端。共享站点结构便于后续扩展，代价是本次需建立通用的网站入口和访问边界。

## 2026-09-10 导航与产品定位修订

用户确认网站面向策略与课程服务。前台采用顶部 Logo 和“策略”菜单，首项为“市场状态”；首页提供品牌介绍与市场状态入口。数据管理归独立 `/admin` 区域，前台无管理入口。研究档案、实验版本与对照不属于产品导航，替代此前“保留已有研究页面”的导航要求；历史静态链接暂保留兼容。课程与定稿策略可视化后续独立交付。

前端采用 React + TypeScript + Vite、Tailwind CSS v4 与 shadcn/ui，基础组件源码纳入仓库维护。既有 Go 网站服务及 Access 验证边界保留。
