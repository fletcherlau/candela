# ADR-0007: 市场状态随历史修订重算，不保留旧版本

- 状态：已接受
- 日期：2026-09-07

市场总览的指标和市场状态以修正后的完整日线历史为准；历史重同步修正数据后，受影响月份及之后的 MACD 和市场状态随之重算，当前正式／暂算状态也按有效数据更新，不保留同一月份在修订前的市场状态版本。正式月份的完成条件、暂算结果的未确认属性及数据缺失时的可用性规则保持既定口径。

该选择使展示结果与当前有效原始数据一致，并省去市场状态的版本归档；代价是不能重放某次数据修订前网站曾展示的市场状态。同步执行的进度、结果、失败原因及中断／恢复记录仍按 Sync Run 规则保留，用于查询数据维护的执行过程。

展示一致性补充（2026-09-09 确认）：同步及重算期间暂存上一套完整展示结果，成功后整体替换；失败或取消标记更新未完成。暂存不构成历史版本归档，也不允许旧结果绕过正式待同步或暂算滞后的规则。
