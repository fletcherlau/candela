# 四标的轮动历史回测（#28）

## 实现口径

页面 `/strategies/four-etf-rotation` 默认展示最新有效数据日之前一年，支持日期、滑块、拖动缩放、平移、快捷区间，以及四只 ETF 的买入持有对照。收益、区间回撤和收盘后仓位使用同一套历史结果。对照为后复权毛收益，策略为扣费净收益。

计算版本 `v1.4-close-5pp-cash0-cost10-v1`：ER20、YZ20/240、1200 个有效波动率分位、70/40 节流、δ=0.005、实际仓位偏差达到 5 个百分点才微调，无安全阀／吊灯。零现金收益，单边成本 0.1%，按成交金额扣费并精确求解扣费后目标权重。采用完整日线信号、当日收盘价近似成交；不模拟历史溢价过滤，页面显式说明。新持仓不获得成交前收益。

指标只使用有效行情样本。基金完整日线和因子从一致快照读取，因子只向前延续，缺失不补 1。未确认的交易日缺口会截断发布并显示原因。

实际数据有两次整日停牌，已由基金公告核实并限定到精确代码／日期：

- 创业板 159915.SZ：2021-02-08，持有人大会计票日停牌。[基金管理人公告](https://pdf.dfcfw.com/pdf/H2_AN202102081459963456_1.pdf)，[基金招募说明书公告索引](https://static.cninfo.com.cn/finalpage/2021-07-29/1210591305.PDF)。
- 纳指 513100.SH：2022-01-13，份额拆分日停牌，次日复牌。[国泰基金公告](https://static.cninfo.com.cn/finalpage/2022-01-12/1212149066.PDF)。

这两日保留日历位置，停牌标的不参与买卖及指标采样；持有它时不调仓，以最近有效后复权收盘估值，复牌后用实际复权价恢复。未写入任何伪造原始 OHLC，页面悬停说明停牌。新缺口仍需核实，不能自动猜测为停牌。

## 自动更新与一致性

- `GET /api/rotation/backtest` 经原有 Access 保护，由 web 转发到受内部密钥保护的 `GET /api/v1/rotation/backtest`。
- 版本 3 迁移只新增 `rotation_result`、`rotation_coverage`、`rotation_calendar`，保留旧表。结果和待更新状态持久化。
- ETF HTTP、one-shot、收盘日报共用同步观察边界，以 MySQL 命名锁避免同步途中发布。完整同步结束后后台更新；浏览器只读取结果。
- 原始 ETF 日线／因子 upsert 与结果 revision 递增在同一事务，历史修订使结果失效。发布条件检查 revision，旧计算不能覆盖新修订。更新失败保留上次完整结果与真实截止日。
- 重启恢复 pending/computing 的重算；中断的原始行情同步标记失败，等待再次同步，不把不完整原料发布成功。本项不实现 #20 的通用同步恢复。
- 沿用已有 cron：服务器 UTC 10:00（北京时间 18:00）收盘日报先同步、随后触发回测；不改 cron 或主动触发机器人推送。未来 #21／#23 的持久同步和策略名单改造应保留这一共享刷新边界。

## 验证

- `go -C syncer test -race ./...`，配合 `ROTATION_TEST_DSN` 指向专用 `candela_rotation_test`。覆盖资金守恒、成交成本、调仓边界、负分缓冲、预热、停牌、同步触发、失败保留、重启重算和历史修订与旧计算竞争。
- `go -C web test -race ./...`、前端构建和 8 项 Playwright 测试通过。浏览器覆盖登录保护、默认一年、拖动缩放、日期复位、对照勾选、仓位、手机布局和读取失败保留结果。
- 真实行情副本在隔离库预演，有效结果 2018-07-26 至 2026-09-15，共 1,976 个交易日。独立 Python 持仓份额计算逐日比对净值、持仓与权重全部一致，净值最大绝对差约 8.35e-14。
- 隔离测试库与生产库分开；研究脚本和旧研究输出不改写。

## 发布与回退

发布镜像 `candela-syncer:rotation-20260916` 与 `candela-web:rotation-20260916`，只更新 syncer 和 web。原镜像保存为对应的 `before-rotation-20260916` 标签，原 Compose override 与行情输入／schema 备份保存于忽略目录 `.scratch/rotation`，不含在提交中。

回退使用备份 override 和原环境，仅执行两个服务的 `up -d --no-deps --no-build`；新增三张表保留，不删除数据库或行情。首轮更新通过正式 ETF 同步接口触发，随后验证完整结果与既有业务目录。
