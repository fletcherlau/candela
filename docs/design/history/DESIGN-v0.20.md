## 2. 最重要的四条规则

1. **以阅读组织页面。** 标题、摘要、章节、论述、图版、图注、口径说明构成主线。操作服务于阅读，不占据首屏中心。
2. **正文与控件使用墨色。** 页面标题、正文、关键数字、导航和普通按钮均为黑灰色。数字的重要性通过字号、位置与间距表达。
3. **颜色留给数据。** 折线、柱体、热力格、系列标记和必要的选区可使用高辨识度色彩。同一序列在全页保持同色。
4. **卡片是承载图表的纸页。** 用中性底色、细边与留白体现层次。纸面已选定 B：净白、浅灰细边、12px 圆角、无卡片阴影；历史对照见第 15 节；正文、目录、边注、摘要指标不装入独立纸卡。

避免：每一段都包卡片、每个指标一种底色、满屏渐变、彩色大标题、玻璃拟态、旋转图版、发光按钮、为装饰创造无含义数据图形。

### 数据图形

以下是已选定的 **A2 · 胭脂湖蓝**，已应用于报告折线、图例、表格系列标记和月收益热力图。其他配色仅保留为历史对照，见第 16 节。

| 系列 | A2 定稿颜色 | 第二种编码 |
| --- | --- | --- |
| 轮动策略 | 胭脂红 `#C4435B` | 1.6px 实线 |
| 红利 | 湖蓝 `#287E9A` | 1.2px 实线 |
| 黄金 | 赭金 `#927A29` | 虚线 |

这些是系列色，不是涨跌、成功或错误色；此映射只用于当前样板的数据语义。新图选择所需的最少颜色，不要求凑齐五色。优先显示 2–3 条序列，其余可选；图例文字保持墨色，用短线或小点对应数据色。

月度正负收益采用发散色阶：`#287E9A → #8FBAC7 → #F5F5F3 → #DD9CA7 → #C4435B`，分别对应 `−6 / −3 / 0 / +3 / +6%`。湖蓝为负、胭脂红为正，零点接近纸色。必须同时提供方向说明、数值范围、带符号的精确数值及可读数据列表。正负方向是本图约定，不扩展成产品通用涨跌语义。

强度或数量图使用顺序色阶；围绕有意义中点的变化图才使用发散色阶。渐变必须对应数据，不能用作任意曲线的装饰填色。K 线等已有金融语义遵循对应产品约定，并保留非颜色编码。

普通文字对比度至少 4.5:1，大字至少 3:1，关键曲线与控件边界至少 3:1。热力格文字根据实际填色使用深墨或白色；不能固定一种字色后默认所有色阶都可读。

## 4. 字体与阅读尺度

| 场景 | 字体与规则 |
| --- | --- |
| 报告标题、章节、图版标题 | **已选定 A · 细宋**：本地 `Noto Serif SC Variable`，300；回退 `Songti SC, serif` |
| 叙述性正文、摘要 | 同一 `Noto Serif SC Variable`，正文 400；样板中的 300 仅作历史对照；中性墨色 |
| 导航、筛选、表单、表格、坐标与图注 | 本地 `Noto Sans SC Variable`；回退 `PingFang SC, sans-serif`；400–500 |
| 英文阅读标题、正文与混排词语 | **已选定 B · Source Serif 4**；独立 `--english-font`，回退 `serif`；标题 300，正文、混排与英文图注 400 |
| Candela 字标 | 保留 `Alegreya, Georgia, serif` |
| 独立指标、表格数字、图表刻度 | **Source Serif 4**；常规400字重，必要强调500；正体等宽数字 |

默认采用 B · 紧凑研究：中英文正文均为 16px，中文行高 1.8、英文 1.7；正文最大宽度 780px，手机仍保持 16px。桌面中文主标题 36px、英文 30px；手机分别 26px / 25px。章节标题桌面 23px、手机 21px；图版标题桌面 21px、手机 20px。界面标签通常 12–14px，坐标刻度 12px，次级元信息 10–12px；重要内容不得降格为小字。

桌面大数字 36px，单位约其六成；窄屏按可用宽度缩放；数据表数值14px、右对齐，图表刻度与热力数值至少12px。数字保持清晰对比，不用过细字重和过紧字距。金额有千分位，百分比默认两位小数，热力格可用一位并提供精确列表。缺失值使用 `—` 并解释；真实零值显示为 `0` 或指定精度。

标题按中文短语换行，不能出现只剩一个字的尾行。偏好轻字重、纤细笔画，但不能横向压缩字形，也不靠过大的字符间距制造留白。标题使用已选定的 300；正文以 400 为易读基准，300 须结合实际字号和设备比较；小号控件与图注保留 400。字体由本地 Fontsource 依赖提供，使用加载回退；验收时等待字体加载并检查溢出。

## 5. 布局与纸感

以下采用已选定的 B · 紧凑研究。A 舒展阅读仅作为历史对照，完整差异见第 14 节。

- 外层内容最大 1280px，桌面侧边至少 32–48px，手机 20px。
- 主图版最大约 1050px，右侧边注约 190px，列距 40px；中等屏缩小间隔，820px 及以下改为单列，边注接在图版后。
- 首屏：字标和简单导航 → 报告分类 → 研究标题 → 摘要 → 作者/区间/样板说明 → 方法入口。目录处于页边，不做彩色功能面板。
- 章节：编号与短标签 → 描述性标题 → 解释段落 → 数据图版 → 图注、来源和边注。图版至下一节使用桌面 44px、手机 32px 间距，不用重复的大空卡片填充。
- 摘要指标为平面的三列排版，细线分隔，无各自底色、投影或强调色。
- 纸卡使用 `--paper`、1px `--paper-edge`、`--paper-radius` 和 `--paper-shadow`；采用已定稿 B：纯白纸面、浅灰纸边、12px 圆角、无卡片阴影。标准内边距保持 20px，手机 16px；表格单元格上下内边距 10px。
- 默认使用 B 无投影的平整纸面，以留白、细边和弱灰底表达层次。A/C 仅在历史对照中保留原参数。
- 纸感由底色、字形、边缘和留白共同构成。默认不添加颗粒贴图、折痕或纹理到数据区。
- 图表、表格需要宽度时可在自身容器内滚动，整页不产生横向溢出；图表提示框的几何范围也必须限制在图表容器中。
- 正式研究页中非当前阅读主线的工具放入附录，默认折叠；保持可发现的标题、原生展开语义和键盘支持。设计样板中的 `#components` 为本轮校准展开显示。

## 6. 组件契约

| 组件职责 | 视觉 | 行为 |
| --- | --- | --- |
| 报告页头 | 中性字标、简单文字导航、少量期号信息 | 语义导航，窄屏合理换行，跳转链接可用 |
| 报告标题与摘要 | 衬线标题、可阅读的摘要、低强调元信息 | 一个 h1，随后有序章节，不用营销口号替代研究主题 |
| 摘要指标 | 细线分列、墨色大数字、小单位 | 随观察区间联动，明确数据口径，未知不显示为零 |
| 图版纸卡 | 图号、标题、单位、控制区、图形、来源 | 保留加载、空、失败、缺失等适用状态；控件不遮挡数据 |
| 边注 | 细线、小标题、短解释，无独立彩底 | 与具体图表对应，手机移到该图后 |
| 数据表 | 纸面、细横线、数值右对齐、小系列标记 | 排序状态可读，筛选有 label 和无匹配反馈，窄屏内部滚动 |
| Button | 墨底纸色字或透明细边；4px 圆角 | 至少 44px 高度；hover、focus、disabled、pending 含义清楚 |
| Input | 纸底、清晰细边、小圆角；16px 文字 | 持久 label，错误说明与输入关联，不能只用 placeholder |
| ToggleGroup | 中性选中底、明确边界或下划线 | 语义选中状态，方向键移动、空格选择，触摸区域至少 44px 高 |
| Checkbox | 墨色选中、小圆角；部分选择显示短横线 | 标签点击区域至少 44×44px；全选只作用于当前筛选，键盘空格可切换 |
| Dialog | 纸色浮层，清楚标题与说明 | 焦点约束、Escape 关闭和关闭后焦点恢复 |
| 附录 | 细线上下边界、原生展开指示 | 收纳计算与数据工具，展开后保留完整交互 |

图标使用现有 Lucide，24×24 画布采用 1.5 的细线宽；样板和其弹窗保持一致。优先复用当前 shadcn/Radix 组件及 variants，避免引入第二套组件库。图标不是内容层级的替代品，不给每一节加装饰图标。

## 7. 图表规则

1. 一张图回答一个明确问题，依次给出标题、口径、图例与必要控件、图形、来源和解释。时间区间和单位必须可见。
2. 色彩强度可高，坐标与网格保持低强调；网格 1px，优先只保留水平线。主折线 1.6px，比较线 1.2px，同时使用名称和线型；悬停保持线宽，避免指针经过时突然变粗。图例沿用对应线宽。
3. 禁止三维透视和暗示不存在精度的平滑。柱状图保留零基线，折线的截轴必须清楚；缺失点不能自动补零。
4. 区间切换联动指标、曲线、比较表、金额换算和导出。独立图表（如完整三年的月收益日历）必须注明固定范围。
5. 图形不能只靠鼠标悬停读取。提供图表摘要和可访问的数据表/列表；交互图例至少保留一条可见序列。
6. 热力图每格包含符号和值，显示色阶范围；图注交代颜色职责，避免把负收益等同于系统错误。
7. 主折线图桌面 300px 高，手机 280px；根据类型保留必要标签空间。叙述和图版比例服务于内容，不强求等大网格。

## 8. 状态与工程映射

所有适用组件覆盖正常、加载、空、失败与输入错误。数据过期和部分缺失须明确截止日或缺失原因；失败时保留条件，重试入口可用。状态信息用文字和结构表达，不只依赖红绿。

仅做 120–180ms 的颜色过渡；尊重 `prefers-reduced-motion`。不使用图表入场旋转、弹性动画或不断运动的纸纹。

- 页面：`web/frontend/src/pages/design-preview.tsx`。
- 组件试用：`web/frontend/src/components/component-study.tsx`，与报告共享观察周期，组合现有组件完成筛选、选择、详情、CSV 与金额校验。
- 色值职责：`web/frontend/src/lib/design-preview-themes.ts` 保留墨色、系列色和热力色阶；`design-preview-surfaces.ts` 定义纸面候选，`previewThemeStyle` 统一映射到 CSS。
- 样式：`web/frontend/src/style.css` 的 `.design-preview-theme` 及样板专属类名；图表色通过同一配置传入 ECharts。
- 图表容器：`web/frontend/src/components/design-preview-chart.tsx`，SVG 渲染，处理尺寸与字体加载。
- 模拟数据：`web/frontend/src/lib/design-preview-data.ts`；正式业务仍使用已确认的数据接口和领域口径。
- 弹窗 portal 也显式带样板作用域和主题变量，防止出现产品原有绿色。

当前只将本方向应用于样板路由，未迁移整个产品。迁移现有组件时检查 Tailwind 静态颜色与根变量，避免只改变量造成主题混杂。

## 9. 生成组件时的使用方式

先读本文件及相关参考图，再按用户任务选择阅读/分析/管理密度。研究内容使用衬线阅读层级；密集管理操作可使用无衬线，但仍遵守中性界面与独立数据色的分工。任务只要求一个组件时，不扩大成完整网站。

可复用请求：

> 按 `docs/design/DESIGN.md` 生成【页面或组件】。内容是【研究问题、数据、操作】。采用研究报告式阅读结构、B · 净白留白纸面、克制文字和 A2 · 胭脂湖蓝数据色，复用当前 shadcn 组件。实现适用状态、手机与键盘交互，并提供实际运行截图。

验收重点：

- 阅读顺序是“主题—解释—证据—口径”，而非杂乱的功能卡片。
- 文字、指标数字与界面控件保持中性；颜色的每一次出现都有数据或必要状态含义。
- 纸面轻薄，采用 B 的浅灰细边、12px 圆角和无卡片阴影；不存在过度装饰和卡片嵌套。
- 大标题自然断行，正文阅读宽度合适，图注和单位可辨认。
- 不同尺寸无整页横向溢出；图表信息能通过数据表/列表等价访问。
- 关键交互可用，数据与导出一致，图表颜色和文字对比度经过实际检查。

## 10. 数字字体决定与保留样张（v0.7）

- “状态试用”提供正常、加载中、无数据、失败。重新加载展示短暂的模拟加载状态后恢复清单，并保留周期、筛选与选择。空数据可恢复示例，搜索无结果可清除关键词；全部使用固定模拟样本。

样式基准：主动作使用墨底纸色字，次动作使用细边，轻动作使用文字按钮；所有选择态保持中性，数据色只用于系列标记。字段文字 16px，界面标签 12–14px，图标 1.5 线宽；选择框与按钮的有效操作区域至少 44px。导出按钮预留宽度，加载时不推动旁边的操作。

桌面为观察清单加金额换算的两列，1040px 以下将主清单独占一行，640px 以下表单与辅助内容单列。窄屏表格在自身容器内横向滚动，滑动提示位于滚动区域外。减少动态效果偏好下关闭加载指示与骨架的循环动画。正式业务数据及其他路由不在本轮迁移范围。
