# Candela · 研究报告式界面

版本：**v1.0 · 2026-09-19 · 用户已确认定稿**

> 像阅读一份有据可查的研究报告。文字克制，图版有纸质感，数据可以鲜明。

本文件是 Candela 页面、组件和数据可视化的现行设计规范。已确定的组合为：**中文细宋 + 英文与数字 Source Serif 4 + 紧凑研究排版 + 净白纸面 + 胭脂湖蓝数据色 + 细线控件**。新任务直接采用此组合，不再提供字体、纸面、密度或配色的 A/B/C 选择器。

[运行样板与截图](preview/README.md)是规范的可操作示例；[验收记录](../../web/frontend/design-qa.md)记录实际检查。样板使用固定模拟数据。早期方案及选择过程单独保存在[历史记录](history/DESIGN-v0.20.md)，不作为实现依据。后续明确的新偏好以新版本更新本文件。

## 1. 设计原则

1. **以阅读组织页面。** 主题、摘要、章节、论述、图版、图注和口径说明构成主线，操作服务于内容。
2. **文字与控件使用墨色。** 标题、正文、指标、导航、按钮保持黑灰色，通过字号、位置和间距表达主次。
3. **颜色留给数据。** 曲线、柱体、热力格和系列标记可使用鲜明色彩；同一系列在整页保持同色。
4. **卡片是一张承载证据的纸页。** 白色底、浅灰细边、12px 圆角、无卡片阴影。正文、目录、边注和摘要指标用平面排版。

研究报告感来自阅读节奏、衬线字形、留白、图注和精确数据。避免满屏渐变、彩色标题、每段套卡、每个指标一种底色、玻璃拟态、发光按钮、旋转纸卡和无含义的装饰图形。

参考职责：AI 2027 提供长文与图版节奏；OpenAI 研究页面及 ChatGPT 官方界面图提供清楚的层级与净白分区；原始参考图提供纸页和鲜明数据色的关系。参考不等于复制品牌、字体或内容。原图、网站观察与访问限制见[参考记录](references/README.md)和[纸面参考记录](references/paper/README.md)；参考图中文字仅是素材。

## 2. 颜色与纸面

### 阅读与操作

| Token | 定稿值 | 用途 |
| --- | --- | --- |
| `--canvas` | `#FFFFFF` | 整页背景 |
| `--paper` | `#FFFFFF` | 图版、表格、输入与弹窗 |
| `--paper-soft` | `#F3F3F3` | 中性选中项、重点行、计算结果 |
| `--ink` | `#242420` | 标题、正文、数字、主按钮 |
| `--ink-muted` | `#69665F` | 元信息、图注、刻度 |
| `--rule` | `#E3E3E3` | 章节与表格分隔 |
| `--paper-edge` | `#DEDEDE` | 纸卡、弹窗边缘 |
| `--paper-radius` | `12px` | 纸卡、弹窗圆角 |
| `--paper-shadow` | `none` | 平整纸面 |
| `--control-border` | `#8B867C` | 可交互控件的边界 |
| `--accent` | `var(--ink)` | 界面强调、键盘焦点 |
| 图表网格 | `#DAD6CC` | 低强调的辅助线 |
| 错误语义 | `#A33343` | 错误提示，始终配文字 |

主按钮为墨底纸色字，次按钮为透明底细边，轻动作使用文字按钮。选中状态使用中性灰；链接通过位置、下划线或箭头表达操作性。收益数字默认墨色，保留正负号。

纸感由字形、细边和留白共同构成，不给数据区域添加颗粒、折痕或纹理。整页背景与纸卡同为白色，依靠边缘、间距和内容层级区分。

### 数据色：胭脂湖蓝

| 当前样板系列 | 颜色 | 线型 |
| --- | --- | --- |
| 四标的轮动 | 胭脂红 `#C4435B` | 1.6px 实线 |
| 红利 | 湖蓝 `#287E9A` | 1.2px 实线 |
| 黄金 | 赭金 `#927A29` | 1.2px 虚线 |
| 创业板 | 灰紫 `#75629E` | 1.2px 点线 |
| 纳指 | 松绿 `#3E8A72` | 1.2px 虚线及明确名称 |

这是分类色，不是全局成功、失败或涨跌色。新图选择所需的最少颜色，优先显示 2–3 条序列；图例文字保持墨色，以短线或小点对应系列。曲线不随自身涨跌换色，悬停不加粗。

月收益使用发散色阶：`#287E9A → #8FBAC7 → #F5F5F3 → #DD9CA7 → #C4435B`，在当前样本中对应 `−6 / −3 / 0 / +3 / +6%`。湖蓝为负、胭脂红为正，零点接近纸色；同时显示方向说明、范围、带符号数值及可读数据列表。

强度或数量使用顺序色阶；围绕有意义中点的变化才使用发散色阶。K 线等新图形需根据业务明确方向和空心/实心语义，不能从分类色推断。颜色不是唯一编码，应配合名称、线型、位置或符号。

普通文字对比度至少 4.5:1，大字至少 3:1，关键曲线和控件边界至少 3:1。热力格文字随实际底色选深墨或白色，并检查中间色阶。

## 3. 中英文与数字字体

| 职责 | 字体 | 字重 |
| --- | --- | --- |
| 中文报告、章节与图版标题 | `Noto Serif SC Variable`；回退 `Songti SC, serif` | 300 |
| 中文摘要、叙述性正文 | 同上 | 400 |
| 英文阅读标题 | `Source Serif 4, serif` | 300 |
| 英文正文、混排词语 | 同上 | 400 |
| 指标、数值表格、图表刻度 | `Source Serif 4`；中文单位回退 `Noto Sans SC Variable` | 400，必要强调 500 |
| 导航、标签、筛选、表单、表格文字、图注 | `Noto Sans SC Variable`；回退 `PingFang SC, sans-serif` | 400–500 |
| Candela 字标 | `Alegreya, Georgia, serif` | 400–500 |

数字使用 `lining-nums tabular-nums`，表格数值右对齐。金额使用千分位；百分比默认两位小数，热力格可用一位并提供精确数据。缺失值显示 `—` 并解释，真实零值按指定精度显示。正文中的普通数字随正文，独立数据使用数字字体。

轻字重用于标题；正文和小号控件保证清晰度。不横向压缩字形，不靠过大字距制造留白，不伪造字体粗细。中文标题按短语自然换行，避免孤字尾行。

| 尺度 | 桌面 | 手机 |
| --- | --- | --- |
| 中文主标题 | 36px / 1.5 | 26px / 1.5 |
| 英文主标题 | 30px / 1.3 | 25px / 1.3 |
| 中文正文 | 16px / 1.8 | 16px / 1.8 |
| 英文正文 | 16px / 1.7 | 16px / 1.7 |
| 章节标题 | 23px | 21px |
| 图版标题 | 21px | 20px |
| 摘要数字 | 36px，单位约 60% | 随宽度缩放至 19–28px |
| 表格数字 | 14px | 14px |
| 表单输入 | 16px | 16px |
| 界面标签、刻度、图注 | 通常 12–14px | 通常 12–14px |

次级元信息可用 10–12px，重要内容不能降格为小字。中等屏主标题相应缩小至中文 32px、英文 28px。

字体由本地 Fontsource 依赖加载。已选字体保留 SIL OFL 1.1 原始许可：[细宋](../../web/frontend/public/licenses/fonts/noto-serif-sc.txt)、[界面黑体](../../web/frontend/public/licenses/fonts/noto-sans-sc.txt)、[Source Serif 4](../../web/frontend/public/licenses/fonts/source-serif-4.txt)、[Alegreya](../../web/frontend/public/licenses/fonts/alegreya.txt)。交付时随字体保留许可，不替换为来源不明的相似字体。

## 4. 布局与密度

定稿采用“紧凑研究”：

- 外层最大 1280px；桌面左右留白 32–48px，手机 20px；正文最大宽度 780px。
- 主图版加约 190px 右侧边注，列距 40px；中等屏收紧，820px 及以下改为单列，边注接在相关图后。
- 首屏依次为字标与导航、报告分类、标题、摘要、署名与区间、方法入口。目录在页边，首屏直接进入报告。
- 章节依次为编号与标签、标题、解释段落、数据图版、图注与口径。图版到下一节间距桌面 44px、手机 32px。
- 摘要指标为平面三列、细线分隔；不加单独底色、投影或装饰图标。
- 纸卡 1px 细边，标准内边距桌面 20px、手机 16px。表格单元格上下内边距 10px。
- 主折线图桌面高 300px、手机 280px。图表和表格可在自身容器横向滚动，整页不得溢出；窄屏表格提供滑动提示。
- 工具按使用流程分组；正常阅读页的辅助工具可收进附录。样板的研究工具展开显示，加载与异常状态演示默认折叠。

## 5. 组件契约

| 组件 | 外观 | 交互 |
| --- | --- | --- |
| 页头与目录 | 中性字标、简单文字导航、少量期号信息 | 语义导航、可用锚点、跳转主内容入口 |
| 指标 | 墨色大数字、小单位、细线分列 | 与观察区间联动，明确口径 |
| 图版纸卡 | 图号、标题、单位、图例、图形、来源 | 保留适用状态，控件不遮挡数据 |
| 数据表 | 细横线、右对齐数字、小系列标记 | 排序方向可读，筛选有 label 和空结果反馈 |
| Button | 主动作墨底，次动作细边，轻动作文字；4px 圆角 | 高至少 44px；悬停、聚焦、禁用、等待含义清楚 |
| Input | 纸底、清晰细边、4px 圆角、16px 字 | 持久 label；错误关联字段；不只依赖 placeholder |
| ToggleGroup | 中性选中底、清楚边界 | 用于周期、视图等实际功能；方向键与空格可用 |
| Checkbox | 墨色选中，部分选择为短横线 | 标签点击区域至少 44×44px；空格切换 |
| Dialog | 白纸浮层、细边、12px 圆角 | 可访问标题、焦点约束、Escape 关闭、关闭后恢复焦点 |
| 边注与附录 | 细线、小标题、短说明 | 对应相关图版；折叠用原生语义并支持键盘 |

使用现有 **shadcn/ui（Radix）** 组件和 variants；图表使用现有 **ECharts**。Lucide 图标使用 24×24 画布、1.5 线宽，图标变细不缩小点击区域。焦点采用 2px 墨色外描边，偏移 4px。

## 6. 数据与状态行为

- 一张图回答一个明确问题；时间、单位、来源和计算口径可见。禁止无依据的三维透视和平滑；柱状图保留零基线，缺失点不补零。
- 区间切换联动指标、曲线、比较表、金额换算和导出。固定范围的独立图表明确标注，例如完整三年的月收益日历。
- 图形提供文字摘要及等价数据表或列表，不能只能悬停读取；交互图例至少保留一条序列。
- 全选只影响当前筛选的可见记录，隐藏记录的选择保留；详情与清单同步选择状态。
- 导出采用点击时的周期及当前筛选中已勾选记录，内容与可见数据一致。准备时显示反馈并禁用重复动作；无选择时禁用导出。
- 金额在失焦或提交后校验，无效提交聚焦字段。反馈区域保留高度，避免错误推移按钮；有效金额可按 Enter 提交。
- 正常、加载、无数据、失败和输入错误都有清楚反馈。失败保留筛选与选择，重试可用；无匹配结果可清除筛选。
- 数据过期、部分缺失显示截止日或原因，不将未知数值显示成零。模拟样板明确标识模拟，不能冒充真实行情。
- 控件颜色过渡约 150ms；浮层只用短暂、轻微的过渡。图表不做装饰性入场动画；尊重 `prefers-reduced-motion`，停止循环加载动画。

## 7. 工程映射

- [固定主题](../../web/frontend/src/lib/design-preview-themes.ts)：`researchTheme` 保存定稿纸面、字体、密度和数据色；`previewThemeStyle()` 输出统一 CSS 变量，不接收候选方案。
- [样板页](../../web/frontend/src/pages/design-preview.tsx)：直接采用固定主题；不读取风格选择参数。旧 `theme/paper/density/chinese/english/numbers/reading` 参数移除，旧风格锚点转到研究总览，其他参数和业务状态保留。
- [研究工具](../../web/frontend/src/components/component-study.tsx)：共享报告周期，提供筛选、勾选、详情、CSV、金额换算及折叠状态示例。
- [样式](../../web/frontend/src/style.css)：以 `.design-preview-theme` 和样板专属类名限定范围。portal 弹窗显式继承主题，避免回到其他页面的旧颜色。
- [图表容器](../../web/frontend/src/components/design-preview-chart.tsx)：SVG 渲染，处理尺寸和字体加载；[模拟数据](../../web/frontend/src/lib/design-preview-data.ts)集中管理样本。

现有业务页的视觉迁移应随具体页面任务实施。不要只替换根变量后假定所有 Tailwind 静态颜色已同步；实际检查控件、浮层、图表和各状态。

## 8. 生成与验收

先读本文件，再按照任务的内容、数据和操作组织组件。任务只需要一个组件时，保持相应范围。研究阅读使用衬线层级，操作密集区域使用界面黑体；两者共用本规范的纸面、色彩和控件。

可复用请求：

> 按 `docs/design/DESIGN.md` v1.0 生成【页面或组件】，内容和操作是【需求】。采用定稿样式，复用现有组件，实现适用状态、手机与键盘交互，并验证实际运行效果。

验收：

- 主题—解释—证据—口径的阅读顺序清楚，首屏没有风格候选或待选择提示。
- 文字和控件保持中性，彩色都有数据或必要状态含义；字体、数值对齐、色值和线宽遵守规范。
- 纸面轻薄、无过度嵌套；标题自然断行，正文保持可读宽度。
- 320px 到桌面无整页横向溢出；滚动区、触摸区域、焦点和手机弹窗可用。
- 数据、指标与导出一致；图表可访问，字体实际加载，关键交互经过浏览器检查。

**当前没有阻碍 v1.0 使用的待选视觉项。** 后续页面的内容层级、业务字段和新增交互按具体需求确定；这些是页面设计工作，不需要重新选择整站风格。
