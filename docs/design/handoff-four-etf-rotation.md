## 已定稿的页面内容

主要服务已了解策略的持续跟踪者，用于每日查看数据及复盘。只提供计算数据和依据，操作由用户自行判断；不输出买卖、持有、换仓或加减仓指令。教程独立，定投模拟不纳入本轮。

页面上方展示四标的每日数据，可选择有记录的历史交易日：

- 510880.SH 红利 ETF、518880.SH 黄金 ETF、159915.SZ 创业板 ETF、513100.SH 纳指 ETF。
- 六项数据：价格、20 日动量、排名、年化波动率、波动率分位、按波动率分位计算的仓位比例。
- 动量沿用现有 ER 加权公式，取含当日在内的最近 20 个日度数据点；两时点用同一公式和各自的当日行情，不改变策略算法。
- 每交易日固定一份 14:45 参考，不持续追踪最新行情。收盘数据完整后展示两时点对应值及价格滑点。
- 价格滑点只显示带正负号的 bps，以 14:45 价格为基准，不额外显示差额或百分比。

页面下方保留历史回测的净值、回撤和模型持仓，不拆成另一个页面。默认近 1 年，允许手动选择时间范围，最大 10 年；实际历史不足时只展示真实可用范围。切换观察区间不重新初始化模型持仓，历史模型记录与实际账户保持明确区分。

## 时点、缺数与修订

| 场景 | 展示行为 |
| --- | --- |
| 交易日当天 14:45 前 | 上一交易日数据，标明所属日期 |
| 当天 14:45 参考生成后，收盘结果尚未就绪 | 当天固定的 14:45 参考 |
| 四标的收盘数据齐全并完成计算 | 当天 14:45、收盘数据及对比 |
| 14:45 获取失败，收盘尚未就绪 | 上一交易日数据及“今日 14:45 参考缺失” |
| 14:45 完整，收盘数据只到齐一部分 | 保留当日 14:45 参考，显示到齐进度；收盘整组齐全并计算完成后再展示 |
| 14:45 缺失，收盘整组完整 | 展示当日收盘结果，参考及对应滑点对比标为缺失 |
| 选择未留存参考的历史日期 | 显示缺失，不以别的日期、收盘数据或事后现价补造 |
| 非交易日 | 展示最近交易日已发布数据及真实日期 |
| 无可用数据 | 显示空态与原因，未知不填零 |

生成中或不完整的 14:45 参考先沿用标注日期的上一交易日数据，并显示当前状态。手动选择历史日期时保持所选日期，不自动以其他日期替代。

数据源更正收盘行情后，后端重算受影响的收盘指标、排名和对比，完整后更新同日结果。**不保留旧版收盘结果，不建设版本查看功能**；固定的 14:45 原始快照保持不变。修订计算期间可保留当前完整结果并标明更新状态，成功后替换。

## 后端与管理页

- 同步、计算、对比和业务统计由后端完成；前端读取已发布结果和状态。页面读取不应反复拉取最新行情。
- 留存每日固定参考与收盘结果，支持按交易日读取；保存完整的两时点数据及来源、时点与状态，避免通过持仓变化推测排名或编造原因。
- 在独立管理页面提供获取失败后的重试入口，后端执行并返回结果或失败原因。重试保持原交易日与时点，已有原始数据可用于恢复计算；无法补取的数据仍显示缺失。
- 原有鉴权和其他功能保留；本页的数据展示边界不自动改变机器人现有功能。每日业务触发及同步执行遵循现有 ADR，不擅自改变调度架构。

## 已核查的能力缺口

- 现有 GET /api/rotation/backtest 提供已发布历史回测，不提供新的每日六指标归档与两时点查询契约。
- 现有信号接口会取请求当下的行情，并可按标的与日期更新盘中快照；不能直接把再次调用它作为固定 14:45 参考的重试。
- 当前接入未提供按历史时点补取的契约。补采 14:45 原始行情是否可用、如何保持准确时点，需要核实数据源并完善后端能力；不可用时如实报告，不用后来的价格冒充。
- 每日参考留存、完整性检查、收盘发布与修订更新、历史查询、管理页重试，以及前端现有区间业务计算的职责调整，都需要在实现中落实。不能以业务已定稿宣称这些能力已具备。
