# T10：每日自动更新与首版部署验收

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#27](https://github.com/fletcherlau/candela/issues/27)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

通过外部 cron 每日北京时间 18:00 更新启用日线数据，让网站完整呈现更新结果，并保留原有机器人每天收盘报告。

## Acceptance criteria

- [ ] 提供外部系统 cron 的可审阅配置与部署说明，明确 Asia/Shanghai 18:00，不在服务里新增每日业务定时器；启用的中证全指、ETF、申万日线都纳入。
- [ ] 自动日线拉取按交易日历执行；日历不可用显式报告而非猜测交易日，缺触发或缺数据由页面截止日／滞后状态可辨识。
- [ ] 机器人每天收盘报告保留，包括非交易日的既有降级报告；与独立自动同步重合时复用已有执行或串行协调，不能重复并发写入，也不能在数据未就绪时提前算报告。
- [ ] 网站纳入现有部署结构，数据库、syncer、机器人内部端点不扩大公网暴露；沿用已完成 Access／Tunnel，上线检查页面、API 保护及跨站写操作拒绝。
- [ ] 在隔离环境演练首次回填、日常更新、ETF 接入、取消、重启恢复、失败 2 只重试、历史修正、完整发布及旧研究／机器人回归；测试随各项实现，本项不承担此前遗漏的基础测试。
- [ ] 上线前核验实际行情源权限和历史覆盖、迁移备份与回退步骤，列明结果与未满足项；源码完成不等于生产验收。需要生产部署时先准备可审阅结果，不自行改动未经授权的线上配置。
