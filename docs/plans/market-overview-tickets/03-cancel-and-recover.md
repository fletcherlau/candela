# T03：同步取消与服务重启后自动恢复

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#20](https://github.com/fletcherlau/candela/issues/20)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

在数据管理中取消排队或运行中的同步；服务中断恢复后自动续跑未取消的未完成工作，并显示中断与恢复记录。

## Acceptance criteria

- [ ] 排队及运行中的执行均可取消，页面展示取消中和最终已取消；已写数据保留，终态操作有稳定、幂等的结果。
- [ ] 取消意图持久化且与段提交有明确先后关系；取消完成后不再写入新段，正在外部取数的旧执行者返回后也不能绕过检查。
- [ ] 服务恢复后重新取得有效执行权，沿用原始对象、日期范围和已完成检查点继续工作；不扩展到新的日期或新增对象。
- [ ] 取消记录不恢复，已成功部分不重跑；允许因无法确认外部请求结果而重读未完成段，但原始数据不重复。
- [ ] 页面执行详情可查询中断／恢复事件，失权执行者不能提交数据、进度或最终成功状态。
- [ ] 通过数据维护入口加隔离真实 MySQL 验证进程重建、提交与取消竞争、旧执行者恢复响应、跨日恢复、取消后重启；不能仅靠内存 fake 宣称恢复可靠。
