# T01：统一网站入口与只读数据管理

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#18](https://github.com/fletcherlau/candela/issues/18)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

沿用现有 Access 登录进入 Candela，通过独立导航查看市场总览入口和按类别组织的真实数据覆盖信息，并保留已有研究页面。

## Acceptance criteria

- [ ] 提供 Go 网站服务与 TypeScript／Vite 前端；网站服务经内部鉴权读取 syncer，浏览器及网站服务均不直连 MySQL。
- [ ] 数据管理分类列出中证全指、ETF、申万数据的已有覆盖起止日期和状态；未接入、无数据、读取失败分别表达，不用演示数据冒充真实数据。
- [ ] 市场总览拥有独立路由，未完成行情功能前显示明确空态；维护操作只归数据管理，原有研究入口仍可访问。
- [ ] 页面与业务 API 均验证 Access JWT 签名、签发方、目标应用和有效期；内部密钥不出现在静态资源、浏览器请求或日志中。
- [ ] 转发仅允许本站必要业务；拒绝未列入允许范围的内部端点，建立同源及 CSRF 写操作保护供后续操作使用。
- [ ] 有隔离数据下的目录查询测试和少量浏览器流程；验证缺失、伪造、过期及错误应用令牌被拒绝。提供本地启动方式，不修改现有线上隧道或登录配置。
