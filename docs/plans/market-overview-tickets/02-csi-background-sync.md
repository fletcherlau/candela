# T02：中证全指后台回填、增量同步与进度查询

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#19](https://github.com/fletcherlau/candela/issues/19)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

在数据管理中首次同步中证全指全部源端历史，随后发起增量同步；关闭或刷新网页后仍能查询同一执行的真实进度和结果。

## Acceptance criteria

- [ ] 000985.CSI 使用独立 Index Series 和 index_daily 日线存储，不产生 ETF 因子、快照或策略候选；新增结构通过可重复执行的有版本迁移落地。
- [ ] 首次回填源端全部可取得历史，不使用 2010 固定起点；记录覆盖依据，分日期窗口获取并检测截断，区分权限错误、限流、上市／起始日期前的空数据和真实失败。
- [ ] 数据管理能提交回填／增量、查看记录列表与详情、阶段进度、处理数量、截止日和失败原因；处理数量不冒称实际改动行数。
- [ ] 请求先持久接受再后台运行；请求连接断开不取消任务，页面刷新可重新定位任务。提交时固定对象和日期边界，不在后续阶段重新解释“今天”。
- [ ] 相同未结束请求复用记录，同一对象不同请求排队；每段数据与检查点事务一致，并保存执行权以阻止失权进程写入。
- [ ] 用可控行情源和隔离真实 MySQL 验证完整回填、增量幂等、失败记录、重复提交与同对象互斥；本项尚不开放手动取消，自动恢复由下一项完成。
