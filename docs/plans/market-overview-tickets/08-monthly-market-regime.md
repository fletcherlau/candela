# T08：正式与暂算月度状态、策略提示和缺数保护

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#25](https://github.com/fletcherlau/candela/issues/25)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

市场总览同时显示已确认月度状态和当月未确认状态，各自提供策略类型提示；月末缺数、月中滞后和历史不足均有明确保护。

## Acceptance criteria

- [ ] 持久维护交易日历，结合 Asia/Shanghai 时钟、当月最后交易日收盘及官方日线确定应完成月份；缺少日历时不猜测，图表周期不改变状态月度口径。
- [ ] 正式状态至少 34 个有效完成月；暂算使用当月最新官方收盘，可由 33 个完成月加当月组成第 34 个输入；标记月份、截止日及未确认，不用盘中报价。
- [ ] MACD 柱大于或等于零为牛市／趋势跟踪，小于零为熊市／反弹；正式和暂算可相反且分别展示提示，不替代彼此，不自动切策略或下单。
- [ ] 最新应完成月缺必要官方日线时当前正式状态待同步并暂停提示；旧月份仅按真实月份展示，暂算不能填补正式缺口。
- [ ] 月中更新失败保留有效正式状态，暂算标滞后及截止日；新月无官方日线不沿用上月冒充当月暂算，历史不足或无效时不输出牛熊。
- [ ] 正式／暂算与图表使用同一完整数据版本，查询时另按当前日历和维护进度判断可用性，缓存不能绕过待同步保护。
- [ ] 市场查询入口覆盖月末盘前、收盘后未同步／已同步、周末长假、新月无数据、日历缺失、零柱、历史不足和图表切周期；浏览器验证两组状态与提示。
