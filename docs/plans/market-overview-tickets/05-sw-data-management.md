# T05：申万字典、成分与指数日线统一维护

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#22](https://github.com/fletcherlau/candela/issues/22)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

在数据管理的申万分组刷新字典及成分、批量同步指数日线，并使用统一进度、取消、恢复和失败重试。

## Acceptance criteria

- [ ] 展示申万字典、成分归属和指数日线覆盖；字典／成分使用刷新操作，不展示日线日期补数式的无意义参数。
- [ ] 刷新先确保字典就绪，再处理成分归属；保存阶段完成记录，准确报告依赖阶段失败及尚未开始的工作，不冒报成功。
- [ ] 申万日线使用既有独立来源和指数标识，按对象批量增量；申万成员不能被误建为受管理 ETF。
- [ ] 每个可独立重试的数据对象或刷新阶段可查看结果；日线批次仅重试失败对象，刷新保留已完成阶段，复用取消与恢复规则。
- [ ] 旧申万 HTTP 与 one-shot 同样接入统一协调，不与页面操作并发覆盖；既有字典、归属及日线能力保持兼容。
- [ ] 用可控申万源和隔离真实 MySQL 验证阶段失败、成员刷新中断、部分日线失败、恢复与跨入口互斥；页面能完成一轮真实测试数据维护。
