## 任务与依赖

1. [T01：统一网站入口与只读数据管理](01-website-and-data-catalog.md) — 阻塞于：无。沿用现有 Access 登录进入 Candela，通过独立导航查看市场总览入口和按类别组织的真实数据覆盖信息，并保留已有研究页面。

2. [T02：中证全指后台回填、增量同步与进度查询](02-csi-background-sync.md) — 阻塞于：T01。在数据管理中首次同步中证全指全部源端历史，随后发起增量同步；关闭或刷新网页后仍能查询同一执行的真实进度和结果。

3. [T03：同步取消与服务重启后自动恢复](03-cancel-and-recover.md) — 阻塞于：T02。在数据管理中取消排队或运行中的同步；服务中断恢复后自动续跑未取消的未完成工作，并显示中断与恢复记录。

4. [T04：ETF 批量同步、失败重试与旧入口兼容](04-etf-batches-and-retry.md) — 阻塞于：T03。从数据管理批量同步现有 ETF，逐只查看结果，仅重试失败对象；机器人、旧 HTTP 与 one-shot 继续工作并遵守相同执行协调。

5. [T05：申万字典、成分与指数日线统一维护](05-sw-data-management.md) — 阻塞于：T04。在数据管理的申万分组刷新字典及成分、批量同步指数日线，并使用统一进度、取消、恢复和失败重试。

6. [T06：ETF 接入、启停与策略候选隔离](06-etf-enrollment-and-universe.md) — 阻塞于：T04。新增 ETF 后自动回填全部历史并进入日常采集，但不会改变策略候选；支持保留历史的启停，并阻止停用策略仍在使用的 ETF。

7. [T07：中证全指日周月 K 线与 MACD 展示](07-market-chart-and-macd.md) — 阻塞于：T02。在独立市场总览查看中证全指日／周／月 K 线和 MACD，默认近 10 年月线，缩放到全部历史时指标值保持一致。

8. [T08：正式与暂算月度状态、策略提示和缺数保护](08-monthly-market-regime.md) — 阻塞于：T07。市场总览同时显示已确认月度状态和当月未确认状态，各自提供策略类型提示；月末缺数、月中滞后和历史不足均有明确保护。

9. [T09：指定区间历史重同步与修正结果整体发布](09-historical-resync-and-publication.md) — 阻塞于：T05、T08。在数据管理指定中证全指、ETF 或申万日线的日期区间重同步，补缺改错并保留区间外数据；中证全指成功后整套更新图表与月度状态。

10. [T10：每日自动更新与首版部署验收](10-daily-sync-and-release-validation.md) — 阻塞于：T06、T09。通过外部 cron 每日北京时间 18:00 更新启用日线数据，让网站完整呈现更新结果，并保留原有机器人每天收盘报告。

## 验收与边界

- T02 贯通单一指数的后台同步，T03 完成取消／重启恢复，T04 复用后扩展为 ETF 批次及旧入口，T05 再接申万。第一版发布须全部完成，不能把中间可演示切片当作最终可靠性验收。
- T07 在 T02 后即可推进图表，与后续数据维护扩展没有强制先后关系。T08 加入日历和状态卡，T09 汇合指定区间维护与展示修订的一致性验收。
- T06 与 T05 无直接依赖；T10 等待两条路径全部完成。依赖允许独立推进，不表示本轮会启动多个代理。
- 既有 Access／Tunnel 不重新搭建，不新增 Authing、候选编辑或状态历史档案。测试边界与技术选型不重新提问。
- 本地原有领域文档和 ADR 的未提交修改需要在实施开始时妥善纳入工作分支；不能丢失或隐式覆盖，也不迁移其他工作区的代码。
