# T09：指定区间历史重同步与修正结果整体发布

状态：用户已批准并发布，标签 ready-for-agent。正式任务：[#26](https://github.com/fletcherlau/candela/issues/26)。

## Parent

[PRD #17](https://github.com/fletcherlau/candela/issues/17)

## What to build

在数据管理指定中证全指、ETF 或申万日线的日期区间重同步，补缺改错并保留区间外数据；中证全指成功后整套更新图表与月度状态。

## Acceptance criteria

- [ ] 页面可选择日线对象和有效起止日期闭区间；源端重新取数后按主键补缺／更新，不先清空，不改区间外原始记录；ETF 因子阶段遵守既有原始存储语义。
- [ ] 重同步沿用持久执行、原范围固定、重复请求复用、同对象串行、取消／恢复以及批次仅重试失败对象；检查点按本次分段保存，不能使用全表最大日期。
- [ ] 中证全指修订触发受影响月份及全部后续 EMA／状态重算，使用修正后的完整历史；数据已同步与结果正在重算在执行进度中可区分，不能在发布完成前声称展示已更新。
- [ ] 同步或重算中保留上一套完整结果；失败／取消标记更新未完成，成功才整体切换；正式待同步、暂算滞后和真实月份规则始终优先。
- [ ] 重算阶段中断可恢复，取消后不会自动重新发布；原始数据已经提交部分保留。只保留当前展示及必要临时候选，不建立修订前市场状态档案，同步执行日志仍保留。
- [ ] 隔离 MySQL 验证已有更晚数据时仍能补旧洞、区间外不变、分段失败／取消／重启恢复、原始更新与发布竞争、旧计算不能覆盖新结果；通过浏览器验证历史修正后所有后续指标和两组状态一起变化。
