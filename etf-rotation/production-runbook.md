# 生产基线 · 每日操作文档（运行手册）

> 版本 v1.4 · 2026-08-06 · 对应回测：`vol-app-data/rotation7.py` 中 `run(mult=None)`（生产基线/无吊灯）
> 策略构成：**ER 动量轮动 + δ=0.005 差距缓冲 + 70/40 分位节流 + 货币ETF 停车**
> 回测口径（2018-07 ~ 2026-08，收盘执行，单边 10bps）：年化 +29.2%，夏普 1.32，最大回撤 −17.1%
> v1.4 变更：**移除安全阀**。隔离验证（`valve_test.json`）：安全阀 8 年触发 38 次，净贡献为负（年化 −1.85pp、回撤深 3.7pp，前后半段及账户级模拟均成立）

---

## 0. 持仓状态（每天收盘后只需记录 3 个字段）

| 字段 | 含义 | 示例 |
|---|---|---|
| `holding` | 当前持仓标的代码（510880 / 518880 / 159915 / 513100 之一） | `510880.SH` |
| `weight` | 当前实际仓位（0.4 ~ 1.0） | `0.804` |
| 其余为停车 | `(1 − weight)` 部分持有货币 ETF（511880/511990） | 19.6% |

## 1. 数据准备（每个交易日 14:45）

1. tushare `pro.fund_daily` 拉取四标的日线 OHLC（历史全量 + 当日用 14:45 最新价近似）；
2. `pro.adj_factor` 拉复权因子，所有价格**后复权**（`价格 × 因子`，因子前向填充）；
3. 停车腿无需计算（货币 ETF 收益视为每日 ≈ 货基年化/240，无需操作信号）。

> 若某标的当日停牌/缺数据：该标的当日不参与打分；若恰好是持仓标的，则维持持仓与仓位不动。

## 2. 计算指标（每个标的各算一遍）

**动量得分（ER 加权动量，窗口 20 个点）**

```
M_t  = (O + H + L + C) / 4          # 后复权四点均价
L_t  = ln M_t
D    = L_t − L_{t−19}               # 净位移（带符号）
P    = Σ_{i=t−18..t} |L_i − L_{i−1}|  # 路径长度
ER   = |D| / P
score = ER × D                       # 得分，正=上涨动能，负=下跌
```

**YZ 波动率与分位（窗口 20，年化 ×240，分位窗口 1200）**

```
σ²_YZ = σ²_overnight + k·σ²_intraday + (1−k)·σ²_RS ，k = 0.34/(1.34+21/19) ≈ 0.1390
q    = σ_YZ 在过去 1200 个交易日中的分位（并列取半），0~100%
```

**节流权重（70/40 折线）**

```
w(q) = 1                      q ≤ 70
     = 1 − 0.6 × (q − 70)/30  70 < q < 100
     = 0.4                    q ≥ 100（即下限 40%）
```

## 3. 换仓决策（每日仅一次，按此顺序判断）

```
第一名 = score 最大的标的
若 当前无持仓：
    → 买入第一名（执行第 4 节仓位规则）
若 第一名 ≠ 当前持仓：
    差距缓冲：若 (第一名得分 − 持仓得分) ≤ 0.005
        → 不换，继续持有
    否则
        → 换仓到第一名
若 第一名 = 当前持仓：
    → 不换
```

> δ = 0.005 的含义：20 日窗口里约 0.5% 的位移差。差距小于它是噪音，换仓只付成本没有期望。
> **注意**：δ 一次定死，不做滚动调参；每年人工复核一次即可（walk-forward 已证明动态调参有害）。
> **v1.4**：δ 缓冲在任何情况下生效，包括持仓得分 < 0 时（安全阀已移除，不再"无视差距直接换"）。

## 4. 仓位决策

```
目标仓位 = w(持仓标的的 q)          # 换仓时用新标的的 q
空仓部分 = 1 − 目标仓位 → 货币 ETF
```

- 换仓日：卖出旧持仓全部，按目标仓位买入新标的，剩余买入货币 ETF；
- 不换仓日：若 |目标仓位 − 当前仓位| < 5%，**可以不动**（省微调成本）；超过则一笔调整到目标仓位，货币 ETF 反向同调（货基腿零佣金）。

> 死区从 2% 放宽到 5%（2026-08，v1.3）：本金 20 万、佣金万 2.5 不免五口径下，2% 微调单约 4000 元必触发 5 元最低消费（=万 12.5）；5% 微调单约 1 万元同样 5 元（=万 5），触发更少、单笔更划算。w(q) 靠 1200 日分位移动很慢，放宽死区对收益影响是二阶的。

## 5. 执行（14:55–15:00，收盘集合竞价）

| 情形 | 动作 |
|---|---|
| 换仓 | 先卖出旧持仓（全仓），再买入新标的 × 目标仓位，剩余资金买货币 ETF |
| 仅调仓 | 按差额买卖持仓标的，反向调整货币 ETF |
| 不动 | 无操作 |

- 佣金目标 ≤ 万 1，货币 ETF 下单前确认券商零佣金；
- **513100 溢价检查**：溢价率 > 1% 时当日不换入该标的（顺延持有第二名，次日重算）；
- 四只标的均 T+0，当日可回转。

## 6. 成本与预期

| 项目 | 数值 |
|---|---|
| 年换仓次数 | 约 20 次（8 年 160 次）+ 仓位微调 |
| 成本拖累（单边 10bps 保守） | 约 5 pp/年（毛年化 ≈ 34% → 净 ≈ 29%） |
| 成本拖累（单边 3~5bps 实盘目标） | 约 2~3 pp/年，净年化 31%~32% |
| 预期净年化（10bps 口径） | +29.2% |
| 预期最大回撤 | −17% 量级 |
| 保费特征 | 高波动单边牛市后段会跑输（如 2025 黄金行情少赚约 16pp），属机制固有代价 |

## 7. 监控与失效预警

| 指标 | 频率 | 动作 |
|---|---|---|
| 滚动 60 日夏普 < 0.3 持续 4 周 | 每周 | 复查动量信号有效性 |
| 相对不节流基线年化落后 > 5pp 持续 6 个月 | 每月 | 复查节流参数 |
| 持仓标的分位 > 90% 持续 60 天 | 每日 | 留意市场结构变化 |
| 月均滑点 > 10bps | 每月 | 换执行方式/券商 |
| 513100 溢价率 > 2% | 每日 | 暂停换入该标的 |

## 8. 明确不要做的事（已验证结论）

1. 不加吊灯止损/任何价格型止损（与动量引擎相克，回撤反而加深）；
2. 不用排名磁滞（Top2 才换），要用距离缓冲 δ=0.005；
3. 不做二元状态切换（防御/反弹模式），风控只用连续节流；
4. 不做滚动动态调参（δ、70/40 一次定死，年度人工复核）；
5. 不纠结 log 与否（等价）；
6. 不换红利腿标的（已验证：512890 红利低波 2024-01 起同区间年化 −2.2pp、515080 中证红利 2025-01 起基本打平，均无改善；样本短但无任何支持换标的的证据，见 `div_swap.json`）；
7. 不加安全阀（v1.4 移除：8 年触发 38 次，净贡献为负——全区间年化 −1.85pp、回撤深 3.7pp，见 `valve_test.json`。其原始目的是防 δ≥0.04 时的"锁死"事故，δ=0.005 下无此风险，δ 缓冲应在任何情况下生效）。
